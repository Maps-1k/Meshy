# Календарик

Групповой календарь: аккаунты, профили с аватарками, поиск людей по юзернейму, группы с лидером,
события с уведомлениями всем участникам, огоньки-стрики с резистом и подтверждением встреч по NFC.
Интерфейс: матовое стекло, хром, чёрно-белые вставки и яркие акценты, анимированные огоньки.

Клиент (PWA) лежит в `public/`, сервер (Node + Express + Postgres) в `src/`. Сборки нет.

## Запуск на Render

1. Залейте проект в GitHub/GitLab.
2. Render Dashboard: **New + → Blueprint** → выберите репозиторий. Создадутся сервис `calendarik` и база `calendarik-db` из `render.yaml`.
3. Локально выполните `npm install && npm run vapid`. Значения `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY` вставьте в Environment сервиса и поменяйте `VAPID_SUBJECT` на свою почту. Без них всё работает, но push не приходят (уведомления видны внутри приложения).
4. Откройте `https://<имя>.onrender.com`.

Локально: `cp .env.example .env`, поднимите Postgres, `DATABASE_URL=... JWT_SECRET=... npm start`.

## Как устроено под ограничения Render

| Особенность Render | Что сделано |
|---|---|
| Диск сервиса временный | Ничего не пишется на диск. Аватарки (сжатые до 256×256) хранятся в Postgres |
| Free-сервис засыпает через 15 минут и просыпается около минуты | Вход по JWT в cookie (без сессий в памяти). Приложение показывает экран «сервер просыпается». Напоминания хранятся в БД и догоняются при пробуждении |
| Перезапуски и деплои (SIGTERM) | Аккуратная остановка, миграции идемпотентны (advisory lock), пул соединений переживает обрывы |
| Порт и прокси | Слушает `0.0.0.0:$PORT`, `trust proxy`, таймауты keep-alive больше, чем у прокси Render, `/healthz` без обращения к БД |
| Free-Postgres живёт 30 дней | Схема создаётся автоматически. Для постоянной работы возьмите платный план БД |
| Исходящий SMTP закрыт на free | Почта не отправляется вообще (нужна только для входа и уникальности) |

### Уведомления о скором событии, пока сервис спит

Напоминания отправляет функция `tick()`: она забирает созданные к этому моменту напоминания одним атомарным `UPDATE … RETURNING` (дублей нет)
и закрывает просроченные встречи. Вызывать её можно тремя способами, они друг другу не мешают:

1. **Сам сервис**: раз в минуту, пока он бодрствует, и сразу при старте.
2. **Внешний будильник (бесплатно)**: cron-job.org или UptimeRobot зовёт `GET https://<имя>.onrender.com/api/tick?key=<CRON_SECRET>` каждые 5 минут. Это будит сервис и запускает отправку. Учтите: круглосуточное бодрствование съедает почти все 750 бесплатных часов в месяц.
3. **Render Cron Job** (от $1/мес): раскомментируйте блок `cron` в `render.yaml`.

На платном плане `starter` сервис не засыпает, и хватает варианта 1.

## Огонёк и резист

* Встреча считается успешной, если отметились **все** участники группы (в группе минимум 2 человека): огонёк +1.
* Пришли не все: если резист месяца свободен, огонёк не меняется, а резист тратится (1 в месяц на группу). Иначе огонёк обнуляется.
* Встреча, которую никто не открыл, закрывается автоматически через 6 часов после начала по тем же правилам.
* Месяц считается по UTC даты начала встречи.

## NFC-подтверждение

NFC-метка (наклейка NTAG213/215/216) хранит ссылку вида `https://<имя>.onrender.com/#/tap/<секрет>`.

1. Лидер: страница группы → **Метка группы** → «Записать на метку» (Chrome на Android) или «Скопировать ссылку» и запись приложением «NFC Tools» (подойдёт и iPhone).
2. На встрече лидер **первым** прикладывает телефон к метке, встреча начинается (участникам приходит уведомление).
3. Остальные по очереди прикладывают телефон. Когда отметились все, огонёк считается сразу.

Чтение работает и без кнопки в приложении: iPhone XS и новее и Android сами открывают ссылку из метки, нужно лишь быть залогиненным в браузере, который откроется.
Кнопка «Приложить к метке» в самом приложении использует Web NFC и работает только в Chrome на Android.
При передаче лидерства секрет метки меняется: метка старого лидера перестаёт работать. Секрет можно обновить и вручную.

## Права лидера

Лидер добавляет и убирает участников, назначает, меняет и удаляет встречи, переименовывает и удаляет группу, обновляет метку и может **передать лидерство**
(все права переходят новому лидеру, метка обновляется). Выйти из группы лидер не может, пока не передаст лидерство.

## API (кратко)

`POST /api/auth/register|login|logout`, `GET/PATCH /api/me`, `POST /api/me/password`, `PUT /api/me/avatar`, `GET /api/users/search?q=`,
`/api/groups` (+ `/:id`, `/:id/members`, `/:id/transfer`, `/:id/tag`, `/:id/events`), `/api/events` (+ `/:id`, `/:id/finish`), `POST /api/tap`,
`GET /api/notifications`, `/api/push/*`, `/api/tick`.

## Ограничения

* Push на iPhone работают только у приложения, добавленного на экран «Домой» (iOS 16.4+).
* Web NFC (чтение и запись из страницы) есть только в Chrome на Android. На iPhone метки читает сама система.
* Аватарки в БД удобны для небольшого числа пользователей; для большого потока вынесите их в объектное хранилище.
